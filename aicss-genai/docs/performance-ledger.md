# SYCL Performance Ledger

This file is the top-level performance tracker for reproducible SYCL tuning on this machine.

Rules:

- every meaningful backend change gets a new row
- each row must point to the exact artifact directory or file
- compare against the most relevant prior baseline, not a vague memory
- keep workload shape explicit
